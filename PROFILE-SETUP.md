# mothvarya · GitHub profile kit

1. Create a **public** GitHub repository whose name is exactly your GitHub username (for example, `mothvarya/mothvarya` if your username is `mothvarya`).
2. Upload `README.md` and the entire `assets/` folder, keeping the paths unchanged.
3. Set `assets/avatar.png` as your GitHub profile photo manually in Settings → Public profile.
4. Suggested bio: `security research · systems · networks`
5. Pin actual repositories only after choosing which projects to feature.

GitHub profile READMEs show the banner **inside the README**, not as a native top-of-page cover.

The design is a visual concept. The profile README does not claim unpublished vulnerabilities, awards, or fabricated repository counts.
